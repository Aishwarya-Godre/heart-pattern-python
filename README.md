# 💖 Heart with Aishwarya — Python Turtle Graphics

A colorful and creative heart animation project built using **Python Turtle Graphics**. This project draws a beautiful heart on a black background, decorates it with colorful star-like patterns, and displays the name **Aishwarya** in the center.

## ✨ Features

- ❤️ Heart shape created using mathematical equations
- 🌈 Random colors for a vibrant design
- ⭐ Star-like patterns drawn around the heart
- 🖤 Black background for a beautiful contrast
- ✍️ Personalized name displayed in the center
- 🐍 Built using Python's built-in Turtle module

## 🛠️ Technologies Used

- **Python**
- **Turtle Graphics** — for drawing shapes and patterns
- **Math** — for calculating heart coordinates
- **Random** — for selecting different colors

## 🚀 How to Run the Project

**Step 1:** Install Python on your computer.

**Step 2:** Clone this repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 3:** Open the project folder.

```bash
cd Heart-with-Aishwarya
```

**Step 4:** Run the Python file.

```bash
python heart.py
```

A graphics window will open and display the colorful heart design.
